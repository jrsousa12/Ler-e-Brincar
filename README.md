# Ler-e-Brincar

Aplicativo para crianças do Ensino Fundamental Anos Iniciais praticarem leitura, matemática e Língua Portuguesa (BNCC, 2º e 3º ano).

## Para quem usa

- **Abrir:** <https://jrsousa12.github.io/Ler-e-Brincar/> no celular ou tablet. Dá para instalar como aplicativo pelo botão "Instalar" (ou "Adicionar à tela inicial").
- **Sem internet:** depois de aberto uma vez, funciona offline.
- **Sem cadastro, sem anúncios, sem enviar dados:** o progresso fica guardado só no aparelho. Para não perder, use a **cópia de segurança** na área do responsável.
- **O que tem:** histórias com perguntas, atividades de Português e Matemática, missão do dia, caderno de erros (volta no que a criança errou), brincadeiras (Monte a Palavra, Memória, Som e Figura, Mercadinho, Trem dos números, Ordem dos Fatos, Pacotes de contas), desenhos de colorir, selos e relatório para o responsável.

## Para quem mexe no projeto

- Feito só com arquivos estáticos (Vue 3 e Dexie guardados em `vendor/`), sem instalar nada além do Node.js.
- Antes de enviar uma mudança: `node build/tudo.js` (confere tudo e roda os testes).
- Guias: `CLAUDE.md` (regras e resumo dos comandos), `build/CLAUDE.md` (motores), `testes/CLAUDE.md` (testes), `PLANO.md` (o que falta) e `HISTORICO.md` (o que já foi feito).
